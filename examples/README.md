# SemiShape — Usage Examples

This directory contains real example outputs generated by SemiShape.

---

## Example: Plate with Spherical Feet

**Description (Czech):**
```
Vytvoř kvádr 55×35×8 mm s válcovitým otvorem průměru 30 mm uprostřed
a půlkulovými nožičkami r=5 mm v rozích
```

**Description (English):**
```
Create a 55×35×8 mm plate with a cylindrical hole 30 mm in diameter
in the centre and hemispherical feet with r=5 mm in the corners
```

**Generation process in Agent Zero:**

![Generation process in Agent Zero](plate_with_feet_generate.png)

**Rendered result:**

![Result — plate with spherical feet](plate_with_feet_result.png)

**Output files:**

| File | Description |
|------|-------------|
| `plate_with_spherical_feet.stl` | Full plate with hole + 4 hemispherical feet |
| `plate_with_hole_and_feet.stl` | Variation with smaller hole |
| `plate_with_hole_55x35x8.stl` | Plate with hole only, no feet |
| `box_50x30x10.stl` | Simple 50×30×10 mm box |

---

## Notes

- All models were generated from natural language descriptions (Czech or English)
- The active Agent Zero model was used for code generation — no separate model config required
- Execution timeout: 60 seconds; models with complex geometry may need multiple attempts
- Verify all AI-generated geometry before 3D printing or manufacturing
